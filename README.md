# lecture-review-ai

강의평 입력 → AI 항목별 감성 분석 → 웹 대시보드 시각화.

## 목표와 기간
- 기간: 2026-10-20 ~ 2026-10-26 오전 10:00 (Asia/Seoul).
- 3인: 분석 1명, 개발 2명.
- MVP: 핵심 흐름이 동작하는 최소 제품. 사전학습 모델 또는 LLM으로 먼저 완성합니다.
- AI-Hub 데이터로 모델을 개선하는 작업은 MVP 완성 후 여유가 있으면 진행합니다.
- 현재 저장소는 협업 준비 단계입니다. 실행 가능한 앱과 설치 명령은 각 구현 PR에서 추가합니다.

## 폴더
| 폴더 | 역할 | 담당 역할 |
|---|---|---|
| frontend/ | 강의평 입력, 감성 결과, 대시보드 | 개발 A |
| backend/ | API, 입력 검증, AI 연결, 집계 | 개발 B |
| ai/ | 항목 정의, 모델 비교, 추론, 평가 | 분석 |
| docs/ | JSON 계약, 협업 규칙, 일정 | 전원 |

## 협업
1. 이슈에서 완료 조건을 확인합니다.
2. main에서 feat/<이슈번호>-<작업> 브랜치를 만듭니다.
3. 작은 단위로 커밋하고 PR을 작성합니다.
4. 다른 팀원 1명의 검토 후 Squash merge합니다.
5. 병합 후 main을 갱신합니다.

main 직접 작업은 초기 설정에서만 사용합니다. 이후에는 PR을 사용합니다.
현재 무료 플랜에서는 비공개 저장소의 브랜치 보호가 강제되지 않습니다.
승인 1명 규칙은 팀 운영 규칙으로 지킵니다.
팀원 초대와 실제 계정별 할당은 보류 중입니다.
실제 강의평의 개인정보와 API 키는 커밋하지 않습니다.

## 완료 기준
- 강의평 입력부터 항목별 결과 표시까지 연결됩니다.
- 빈 입력, AI 실패, 언급되지 않은 항목을 처리합니다.
- AI 결과를 사람이 표시한 평가 예시와 비교합니다.
- 데모 실행 방법과 알려진 제한을 기록합니다.
