# 일관성 기준 v2 — 로컬 AI 판정 기준

목적은 모델 답에 정답을 맞추는 것이 아니라 같은 의미를 같은 규칙으로 판정하는 것이다. 사용자 요청에 따라 AI가 판정한 로컬 기준이며 팀 합의나 독립 사람 검수로 표시하지 않는다. 기존 Ver 3.1, 4일차 통합 기준을 우선하고 그 안의 애매한 경계를 다음과 같이 구체화한다. 기존 45개 정답은 수정하지 않는다.

| 주제 | 고정 판정 |
|---|---|
| 출결의 엄격함 | 랜덤 호명·대리출석 불가·엄격함 자체는 neutral. '빡셈', 불편, 곤란, 리스크, 의문사처럼 부담·불이익을 평가하면 negative. 출석 문맥의 의문사를 학점으로 옮기지 않음. |
| 시험·수업 난이도 | 어렵다는 사실만은 neutral. 시간 부족·억울함·싫음·못 풀어서 아쉬움은 negative. 어렵지 않다는 사실만으로 positive를 만들지 않음. |
| 같은 항목의 중립 | 같은 판단을 배경 사실로 다시 만들지 않음. 그러나 시험 유형·일정 정보와 시험 시간·공정성 평가가 독립된 문장/명제로 명시되면 exam/neutral과 평가를 함께 보존. 무조건 한 감성만 남기지 않음. |
| 학점 | 학점 결과만은 neutral. 후함·만족·기대보다 낮음은 문맥 감성. 성적 발표를 기다리며 불안했다는 말만으로 학점 부정 생성 금지. 노력 없이 학점을 못 받는다는 경고만으로 낮은 학점 추론 금지. |
| 선수지식 | 기초 부족으로 필요한 예습·복습·준비 시간은 workload. 필요하다는 조언만이면 neutral, 고생·부담이 명시되면 negative. 빠른 진행·설명 부족은 delivery. |
| 질문과 피드백 | 제출한 과제의 채점·결과 피드백은 delivery. 질문 게시판 답변·질문 응대·면박은 professor. 과제에 관한 질문이어도 '질문 답변' 행위라면 professor. |
| 팀플과 발표 | 팀원·분담·팀플 준비 부담은 team_project. 팀플 문맥의 발표 횟수·부재도 team_project. 개인 발표/일반 참여가 명시된 경우 attendance. 시험·개인 과제까지 섞인 전체 일정 부담은 workload로 별도 보존. |
| 학습 가치 | 실제 습득·활용·향상 또는 직접적인 유익함/배울 가치 평가는 learning. 실습 재미·사례 설명·기억하기 쉬움은 delivery. 단순 공부 방법 권고를 실제 학습 성취로 확대하지 않음. |
| 총평·추천 | 독립적인 추천·비추천·적합성 평가는 general_impression. 조건부 추천의 목적만으로 learning/grade 평가를 추가하지 않음. 구체 항목 평가를 다시 말한 결론만이면 그 항목에 합침. |
| 교수의 주관 | 관점·기준이 뚜렷하고 근거가 필요하다는 사실만이면 neutral. 당황·위축·불쾌함 등 부정 효과가 명시되면 negative. |
| 음향 | 청취 방해는 delivery. 단순 시설·공간 자체만 etc. |
| 조건 | 명시적인 대상/상황에 따라 해당 평가가 달라지면 condition. 같은 pair에 조건부/무조건 평가가 섞인 경우 대표 evidence가 지지하는 조건을 기록하고 메모로 범위를 설명. |
| 변경 | 같은 항목의 운영 변경이 직접 언급되거나 전후 상태가 명시적으로 대비될 때 true. '이번 학기' 자체나 다른 사람의 이전 부담만으로 변경 추론 금지. 변경의 원인과 결과를 대표 근거에 포함. |
| 근거 | 감성과 조건·변경을 지지하는 연속 원문 구간. 오타·문장부호를 임의로 고치지 않음. |

v1에서 판단이 갈렸던 30개 리뷰는 이 표로 재판정한다. 모델 출력은 라벨 수정 근거가 아니다. 모든 변경은 변경 전·후·원문 근거·규칙을 기록한다. 재판정 후 파일 해시를 고정하고 이후 후보 결과를 보고 라벨을 다시 바꾸지 않는다.
