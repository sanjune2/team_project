# 로컬 병합 후보 10개 분리

기존 45개는 `data/test_reviews.jsonl`로 유지한다.
추가 후보는 `data/local_review_candidates.jsonl`에 별도로 보존했다.
기존 초안의 ID·원문·정답·근거·메타데이터를 바꾸지 않았다. 파일 줄바꿈만 LF로 통일했다.
두 파일을 합치거나 기존 정확도 분모를 55개로 바꾸지 않는다.

## 사용 이력과 해석

이 10개는 과거 로컬 Qwen 및 프롬프트 실험에서 이미 사용됐다.
따라서 파일 이름을 holdout으로 바꿔도 **프로젝트에서 완전히 처음 보는 평가셋이 되지 않는다.**
현재 45개와 ID·원문 완전 중복은 없지만, 이것은 과거 노출이 없다는 뜻이 아니다.
독립적인 일반화 정확도보다 회귀 점검·추가 라벨 검토에 적합한 재사용 후보로 분류한다.

출처는 `reviews_최동렬_v31_draft.jsonl`의 AI 지원 가상 리뷰 초안이다.
실제 대학 강의평 원문이나 교수자 실명은 사용하지 않았다.
사람이 정답을 교차 검토했다는 근거는 없다.

## 확인한 로컬 증거

다음 저장 결과 모두에서 10개 ID의 예측이 확인됐다.
원본 결과 파일은 로컬에 보관하며 이 PR에 포함하지 않는다.

- experiments/qwen35_4b_baseline/predictions.json
- experiments/notion_alignment/single_predictions.json
- experiments/notion_alignment/two_stage_developer_response.json

ID: r014, r015, r016, r017, r018, r019, r020, r027, r028, r029.
증거 파일 해시와 후보 원본 해시는 `data/local_review_candidates_manifest.json`에 기록했다.
이 이력은 데이터가 GPT-6 Luna의 학습에 들어갔다는 뜻이 아니다. 로컬 개발 과정의 노출을 뜻한다.

## 검사 결과

- 후보 10개, ID·원문 중복 없음.
- 현재 팀 45개와 ID·원문 완전 중복 없음.
- category·sentiment enum, 같은 category·sentiment 중복 없음.
- 근거는 모두 해당 원문의 부분 문자열.
- 출처와 후보의 JSON 필드는 일치한다. 줄바꿈만 LF로 정규화하므로 원본 해시와 후보 해시를 별도로 기록한다.
- `.gitattributes`로 두 분리 데이터의 LF 줄바꿈을 고정해 동결 해시를 보존한다.
- r028의 기존 `primary_type=ambiguous`는 그대로 보존했다. 현재 가이드의 대표 유형으로 정규화하려면 팀 확인이 필요하다.
- 기존 45개와 프롬프트·사전·API 계약은 변경하지 않았다.

## 새로운 holdout을 만들 때

프롬프트·모델 설정을 먼저 동결하고 새 리뷰와 정답을 별도로 작성한다.
사람이 정답을 확인한 뒤 해시와 평가 시점을 기록한다.
첫 측정 전에는 새 문장으로 프롬프트를 수정하거나 few-shot을 추가하지 않는다.
점수를 본 뒤 수정에 사용하면 해당 데이터는 이후 개발 데이터로 구분한다.

현재 CLI 평가는 45개 고정이다. 이 후보 10개로 실행하려고 정답 수를 맞추거나 기존 45개에 끼워 넣지 않는다.
별도 평가를 하려면 별도 분모와 정답 검토 상태를 명시한다.
