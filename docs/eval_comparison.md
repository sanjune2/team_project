# 3일차 45개 평가·프롬프트 개선·모델 비교

평가 기준은 팀 저장소 main `ef1a55d`의 `data/test_reviews.jsonl` 45개다.
정답은 97개 item이며 리뷰별 고유 항목은 93개다. 원본 정답과 로컬 병합 후보는 변경하지 않았다.
사람 교차 검토 완료가 확인되지 않아 모든 결과는 **제공된 1차 라벨 대비 잠정 평가**다.

## 5·6번: 프롬프트 수정 전후

| 조건 | 항목 정밀도 | 항목 재현율 | 항목 F1 | 감성 정확도 | 근거 exact | 실패 | 평균 시간 |
|---|---:|---:|---:|---:|---:|---:|---:|
| 기존 프롬프트 / Luna none | 90.43% | 91.40% | 90.91% | 92.31% | 98.99% | 0/45 | 2.645초 |
| 수정 1회 / Luna none | 94.62% | 94.62% | 94.62% | 92.63% | 99.00% | 0/45 | 2.559초 |

모델·정답·temperature=0·reasoning=none·timeout=30초·retry=0·출력 한도=4000을 유지했다.
프롬프트 해시는 실행별 상세 보고서에 보존했다. few-shot 예시 3개와 은어 사전은 수정하지 않았다.
새 문장은 기존 규칙의 경계를 명확히 한다. 조교=etc, 시험 구성 사실=exam, 별점≠학점, 반어·명시된 학습 성과·추론 금지를 강조했다.
이 45개로 프롬프트를 조정했으므로 수정 후 점수는 개발 데이터 재평가다. 별도 미사용 데이터의 일반화 성능은 아니다.

- 리뷰 전체 항목·감성이 일치한 수: 25/45 → 32/45.
- 맞게 바뀐 리뷰: t02, t07, t08, g05, g08, g10, m03, c04, c14.
- 새로 차이가 생긴 리뷰: g07, m04. m04는 delivery 대신 learning으로 바뀌어 라벨 경계 검토가 필요하다.
- condition 유무 일치: 3/4 → 3/4. 조건 내용 의미는 사람 검토 대기다.
- mentions_change 값 일치: 4/5 → 3/5. 이 지표는 퇴보했다.

| 중점 사례 | 기존 → 수정 후 해석 |
|---|---|
| c14·c15 | c14 누락은 해소, c15는 두 실행 모두 정답 인정. 사전 등록 패턴이라 일반화 증거는 아님. |
| c02 반어 | 총평의 잘못된 긍정은 없어졌으나 총평 부정도 누락. 완전 해결 아님. |
| c11 오타 | 두 실행 모두 exam 부정이 누락. |
| c07 공격적 표현 | 두 실행 모두 항목·감성은 일치. summary 정제의 사람 검토는 별도. |
| c05 조건 | exam 부정이 누락되고 workload 또는 delivery가 나옴. 가이드의 선수지식 경계와 정답 조건을 팀에서 확인. |

## 7번: 같은 프롬프트·low 설정의 모델 비교

두 모델은 수정 프롬프트·데이터·스키마·reasoning=low·출력 한도=4000·timeout=30초·retry=0을 공유한다.
temperature는 두 요청 모두 생략했다. none 실행과 low 실행을 모델 차이로 비교하지 않는다.
각 실행은 순차 호출이며 두 비교 프로세스는 같은 컴퓨터에서 일부 시간 겹쳐 실행했다. 시간은 단일 실험 관측값이다.

| 모델 / 설정 | 항목 F1 | 감성 정확도 | 근거 exact | 평균 시간 | 실패 | 45개 토큰 비용 추정 USD |
|---|---:|---:|---:|---:|---:|---:|
| gpt-6-luna / low | 94.62% | 94.62% | 97.96% | 3.231초 | 0/45 | $0.017950 |
| gpt-5-nano / low | 81.36% | 85.90% | 100.00% | 4.798초 | 0/45 | $0.019866 |

**모델 판단: 현재 `gpt-6-luna` 유지.** 이번 45개에서 nano는 항목 추출과 감성 결과가 낮았고 처리 시간이 더 길었다.
단가가 낮아도 출력·추론 토큰이 증가하면 실행 비용이 더 커질 수 있다. 실제 사용 토큰을 기준으로 비교했다.
nano는 공식 모델 페이지에서 Deprecated로 표시된다. 이번 비교 결과만으로 서비스 모델을 교체하지 않는다.

비용은 실측 input/output tokens에 Standard 단가를 곱한 **캐시 미적용 추정**이다.
캐시 할인·캐시 쓰기 요금·세금·실제 청구액은 반영하지 않았다. 청구서 검증 결과가 아니다.
단가(USD/100만 토큰): Luna 입력 0.10 / 출력 0.50, nano 입력 0.05 / 출력 0.40.
출처(2026-10-22 확인): [OpenAI Pricing](https://developers.openai.com/api/docs/pricing), [GPT-5 nano](https://developers.openai.com/api/docs/models/gpt-5-nano).

## 해석·완료 범위

- 실제 API 180회가 모두 성공했다. HTTP·웹·팀 통합은 이번 평가 범위에 포함하지 않았다.
- 명시된 condition 4개는 모두 조건이 있는 사례, mentions_change 5개는 모두 true다. 정답 없는 필드는 평가에서 제외했다.
- 조건이 없는 사례·변경이 없는 사례의 오탐률은 계산할 수 없다. condition 의미 정확도는 확정하지 않았다.
- c14·c15 제외, t02·c11 제외, 네 사례 모두 제외한 결과는 실행별 상세 보고서에 함께 기록했다.
- 동렬 담당 15개 라벨 검토 초안은 docs/label_review_day3.md에 저장했다. 사람 교차 검토 완료가 아니다.
- 프롬프트 수정은 로컬 후보이며 mentions_change 퇴보와 라벨 경계를 팀에서 검토해야 한다.
- 기능 브랜치: feat/day3-evaluation. 평가 코드·결과 문서와 프롬프트 후보를 PR로 제출한다. 병합 전 팀 검토가 필요하다.
- 로컬 데이터 병합 후보의 PR은 이번 평가와 분리한다. 데이터 파일은 이번 변경에 포함하지 않는다.
