## 통합 확인

- 20개 입력 중 성공·실패 건수가 합계 20인지 확인한다.
- g10·c08·c10은 평가 없음으로 items=[]와 overall_sentiment=null을 확인한다. 이들은 호출 실패가 아니다.
- t04·t07·t08·m04·c05의 혼합 감성, t02·g05·m09·m10의 중립을 확인한다.
- g07·c02의 반어 총평, c14·c15의 산타 밈은 실제 결과를 확인한다. 오답이 있으면 그대로 기록한다.
- 차트 비율과 건수, 주요 의견의 원문 근거, 근거 하이라이트를 대조한다.
- 실패가 발생하면 해당 리뷰가 집계에서 제외되는지 확인한다. 이 20개는 실패를 강제로 발생시키지는 않는다.
- c05·m04는 라벨 경계 검토 사례이므로 docs/label_boundary_decision.md와 함께 본다.
