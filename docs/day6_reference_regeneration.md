## 10-1 변경

`scripts/rescore_consistency.py`는 CRLF를 LF로 정규화해 해시를 비교한다.
나머지 바이트가 바뀌면 검사는 실패한다. 원래 raw 해시는 manifest에 보존했다.

과거 64개 기준선은 main `fedf04d`의 기존 학기 결과에서 `baseline64_frozen.json`으로 고정했다.
재채점은 이 파일을 사용한다. 새 포털 결과로 과거 점수가 달라지지 않는다.
실험 프롬프트도 `prompt_v3_frozen.txt`로 보존했다.

실행 프롬프트의 모듈 설명을 v3 main 반영 상태로 고쳤다.
few-shot을 테스트셋에서 가져오지 말라는 경고를 복구했다.
`build_instructions()`의 실제 출력은 당시 실험 프롬프트와 같음을 확인했다.
