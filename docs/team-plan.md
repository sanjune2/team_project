# 일정과 역할

## 계정 할당 준비
| 역할 | 담당 범위 | 이슈 |
|---|---|---|
| 분석 1명 | 항목, 데이터, 모델, 품질 평가 | AI baseline |
| 개발 A | 입력 UI, 대시보드 | Frontend |
| 개발 B | API, 검증, AI 연결, 집계 | Backend |
| 전원 | JSON 계약과 통합 데모 | 계약 / 통합 |

팀원 이름과 GitHub 계정은 아직 입력하지 않았습니다.
초대 후 역할을 확인하고 이슈의 Assignees에 실제 계정을 연결합니다.
Organization Member 추가만으로는 저장소 Write 권한이 생기지 않습니다.
조직 기본값은 Read이므로 이 저장소에 별도 Write 권한이 필요합니다.
