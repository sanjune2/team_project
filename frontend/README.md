# Frontend

React (Vite) 결과 화면과 가나대학교 포털 레퍼런스 페이지입니다.

- 실행 방법과 화면 주소는 [루트 README](../README.md)를 보세요.
- 화면을 만들거나 고칠 때는 [DESIGN_GUIDE.md](DESIGN_GUIDE.md)를 먼저 따릅니다.
- 포털은 `public/reference/`의 결과 파일을 읽어 그립니다 (서버 호출 없음).
- `#analyze` 화면은 백엔드 `/api/analyze`를 호출합니다 (개발 서버가 8000번 포트로 전달).
- API 키는 화면이나 브라우저 환경변수에 넣지 않습니다.
