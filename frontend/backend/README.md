# Backend

강의평 수신, AI 호출, 결과 검증과 대시보드 집계를 구현합니다.
담당: 개발 1명. 실제 계정 할당은 팀원 초대 후 진행합니다.

- POST /api/v1/analyze: docs/api-contract.md 계약을 따릅니다.
- 빈 입력, 길이 초과, AI 지연과 응답 형식 오류를 처리합니다.
- API 키는 서버 환경변수로만 읽습니다.
- AI 미연결 시 개발용 mock 모드를 명시합니다.
- not_mentioned는 감성 비율 계산에서 제외합니다.

현재는 협업용 폴더입니다. 실행 서버는 아직 없습니다.
